Enterprise Knowledge Chatbot (2023)

Key Achievements

  • Enterprise RAG Architecture: Engineered an enterprise-grade RAG chatbot on Azure to automate Tier-1 technical support, ingesting 200+ internal documents and reducing ticket volume by 40%.
  • Model Fine-Tuning: Fine-tuned Llama 7B / Llama 3.2 70B on Azure ML using QLoRA and a synthetic dataset of 1,000 dialogue pairs, aligning model responses with corporate protocols and tone.
  • High-Throughput Serving: Architected a high-throughput inference pipeline using vLLM with PagedAttention on AKS, enabling concurrent serving of 200+ users with low retrieval latency.
  • Azure Integration & Search: Integrated the solution into Microsoft Teams via Azure Bot Service and Entra ID, implementing a Hybrid Search (Vector + BM25) strategy to ensure 92% precision on technical query retrieval.
